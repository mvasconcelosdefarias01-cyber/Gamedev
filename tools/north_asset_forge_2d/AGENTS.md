# Propriedade e operação

Este é o projeto local novo de geração de assets. Não afirmar que usa capacidades de um produto externo chamado North Asset Forge 2D.

- Editar somente este diretório, `../../assets/` e `../../docs/ASSET_PRODUCTION.md`.
- A fonte é `forge.py`; exports são determinísticos e podem ser regenerados pelos comandos do README.
- Preservar os IDs e pivôs do contrato em `../../docs/INTEGRATION.md`.
- Nunca exportar as imagens de referência dos documentos como sprites.
- Avaliar `sample` antes de `full`; registrar limites entre validação técnica, avaliação visual e teste humano.
- Não invocar provedores pagos nem usar credenciais sem autorização específica.
- Não subdelegar.
